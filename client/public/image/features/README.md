## 🚀 **Alternativas se não quiser baixar imagens:**

### **Opção 1: Usar cores sólidas**

```typescript
// Em vez de image, use background gradiente
background: 'linear-gradient(135deg, #6DAEDB, #4F91C3)';
```

### **Opção 2: Usar ícones grandes**

```typescript
// Usar apenas os emojis/ícones em tamanho maior
icon: '🤖'; // em fontSize: '4rem'
```

### **Opção 3: Voltar para Unsplash**

```typescript
// Manter as URLs do Unsplash (já estão otimizadas)
image: 'https://images.unsplash.com/photo-1531746790731-6c087fecd65a?w=600&h=400&fit=crop';
```

## 📝 **Notas Importantes:**

- Todas as imagens do Unsplash, Pexels e Pixabay são **livres para uso comercial**
- Não é necessário atribuição, mas é uma boa prática
- Otimize as imagens antes de usar (comprimir para web)
- Mantenha consistência visual entre as imagens

**Dica:** Use ferramentas como TinyPNG ou ImageOptim para otimizar o tamanho dos arquivos.
